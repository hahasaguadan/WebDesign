# WebDesign

大學「網頁設計」課程練習：用 HTML + CSS 製作的個人介紹網站。

## 內容

| 檔案 | 說明 |
| --- | --- |
| `hello.html` | 個人網站主頁（自我介紹、興趣、運動） |
| `dialogue.html` | 對話頁面練習 |
| `*.jpg` / `*.png` / `favicon.ico` | 網頁使用的圖片與社群圖示 |
| `link/` | 上課時收集的參考資料捷徑（見下方） |
